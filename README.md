# DSH 群聊日记

本仓库用于私有归档 DSH 内测期间的群聊精选、成员画像、事件记事和 Issue 汇总。

> **仅限获得授权的内部成员查看。** 文件中包含群成员昵称和精选发言，请勿转发到公开仓库、公开网盘或社交平台，也不要开启 GitHub Pages。

## 当前归档

- [DSH 内测群每日档案 · 2026-08-04](./DSH内测群每日档案-0804.html)

## 如何查看

GitHub 文件页面不会直接运行交互式 HTML。请下载对应的 `.html` 文件，然后使用 Chrome、Safari 或其他现代浏览器打开。

文件已经内嵌页面样式、交互脚本和当日快照数据，不依赖同目录下的 JSON 或 JavaScript 文件。Issue 详情链接指向私有仓库 `dsh-external/issues`，查看者还需要拥有该仓库权限。

## 文件命名

每日文件遵循以下格式：

```text
DSH内测群每日档案-MMDD.html
```

例如，8 月 5 日对应 `DSH内测群每日档案-0805.html`。不同日期的文件分别保留，不覆盖历史归档。

## 数据来源

- 群聊：本机微信 4.x 数据库中的 `【官方】DSH内测群`；
- Issue：私有仓库 [`dsh-external/issues`](https://github.com/dsh-external/issues)；
- 身份归属：微信左侧且有署名的气泡属于其他群成员，右侧绿色气泡属于“少女阿原”；
- 页面只保留聚合统计、精选信号、成员画像和事件候选，不包含完整聊天记录、微信数据库或解密密钥。

## 更新方式

维护者的 Mac 会在北京时间每天 05:00 从本机微信和 GitHub Issue 重新生成当天 HTML，以覆盖深夜至凌晨仍然活跃的群聊内容。

本机生成与本仓库归档目前是两个独立步骤：**每日 HTML 尚未自动上传到本仓库**。只有经过明确确认的文件才会提交到这里。

## 隐私边界

Private 仓库只能限制 GitHub 访问权限，不能阻止已获权限的人下载或继续转发文件。添加协作者前，请确认对方确实需要查看内测群内容。
